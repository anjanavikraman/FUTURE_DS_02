# Customer Retention & Churn Analysis

## Project Overview
This project focuses on analyzing customer retention and churn patterns using the Telco Customer Churn dataset. The analysis was performed using **Power BI** to identify customer churn behaviour, retention rates, and factors influencing customer loss.

## Objectives
- Analyze overall customer churn and retention.
- Identify churn patterns based on contract types.
- Understand the relationship between customer tenure and churn.
- Analyze customer distribution by internet service and payment method.
- Build an interactive Power BI dashboard.

## Tools & Technologies
- Power BI
- Power Query
- DAX
- Kaggle Dataset

## Key Performance Indicators (KPIs)
- Total Customers: 7,043
- Churned Customers: 1,869
- Retained Customers: 5,174
- Churn Rate: 26.54%
- Retention Rate: 73.46%
- Average Tenure: 32.37 Months

## Dashboard Analysis
The dashboard includes:
- Customer Churn by Contract
- Customer Churn by Tenure
- Customers by Internet Service
- Churn Rate by Contract
- Customers by Payment Method
- Customer Churn Trend by Tenure
- Churn by Online Security
- Overall Churn Rate Gauge

## Dataset
The project uses the Telco Customer Churn dataset from Kaggle.

## Project Deliverable
The final deliverable is an interactive Power BI dashboard (`FUTURE_DS_02_Customer_Retention_Churn_Analysis.pbix`) presenting customer churn and retention insights.
